# StateSeal 中文文档

StateSeal 是 Coding Agent 的本地只读运行时智能层，只观察 Agent 自有会话日志和
本地产物，不参与执行。

| 文档 | 用途 |
| --- | --- |
| [快速上手](getting-started.md) | 安装并打开实时全景图 |
| [运行全景图](runs-console.md) | 理解会话列表、DAG、时间线和证据等级 |
| [产品全景](product-map.md) | 查看架构、模块和路线图 |
| [英文观察模型](../observation-model.md) | 理解数据源、隐私、归因和声明边界 |

旧版“受控交付”文档仅作为历史研究材料保留，不属于当前产品入口，也不应用于配置
Agent 执行。
