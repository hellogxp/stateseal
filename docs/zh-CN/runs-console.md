# 交付全景图

![StateSeal 交付全景图](../assets/stateseal-runs-console.svg)

`seal ui` 是受支持本地 Agent 交付会话的只读投影。

## 它回答什么

| 问题 | 页面区域 |
| --- | --- |
| Agent 最终留下了什么？ | 当前状态与代码变化卡片 |
| 每次检查对应哪个代码状态？ | 交付证据 DAG |
| 后续编辑是否使旧结果过期？ | 证据新鲜度与诊断发现 |
| 生成了什么报告或文档？ | 产物清单 |
| 哪里失败，依据是什么？ | 首要诊断与 finding basis |
| 哪些是事实、派生或推断？ | Observed / Derived / Inferred 标签 |

## 页面信息层级

首页先展示交付结果：会话状态、证据态势、变更文件、检查和发现。工具级噪声不进入
主 DAG，只保留在审计时间线。详情页依次展示当前状态、首要诊断、证据 DAG、
诊断发现、文件修改、检查新鲜度、产物和时间线。

## 状态与证据态势

- **观测中**：尚未看到 Agent 完成事件；
- **Agent 已结束**：Agent 报告完成，不等于 StateSeal 审批；
- **需要关注**：检测到失败、证据缺口或旧证据。

证据态势独立表达：当前、失败、旧证据、缺口或未知。

页面没有任何回到 Agent 的动作：不阻断、不批准、不 Apply、不恢复，也不控制 Prompt。
