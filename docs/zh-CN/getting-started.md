# 快速上手

## 安装与启动

源码构建需要 Go 1.24 或更高版本：

```bash
make install
export PATH="$HOME/.local/bin:$PATH"
seal ui
```

StateSeal 会打开本机页面，旁路读取近期受支持的 Agent 会话。无需初始化项目、
接入 Agent、安装 Hook、配置策略或启动代理服务。

```bash
seal ui --address 127.0.0.1:9137
seal ui --no-open
```

## 如何阅读一次交付

```text
交付请求
   ↓
观测代码状态 ──→ 绑定到各状态的检查
   ├───────────→ 交付产物
   └───────────→ Agent 完成声明
```

建议按以下顺序查看：

1. **当前工作区状态**：分支、提交/dirty 摘要和代码变化量；
2. **检查与证据新鲜度**：检查发生在最后一次编辑之前还是之后；
3. **诊断发现**：每个警告的事实依据和证据等级；
4. **审计时间线**：经过脱敏的源事件顺序。

“证据匹配当前状态”只表示至少一个可识别的通过检查发生在最后一次观测编辑之后，
不代表覆盖了全部需求、代码语义正确或 StateSeal 批准了交付。

## 隐私默认值

StateSeal 只监听回环地址，不上传会话数据；通用工具参数默认隐藏，输出长度受限，
常见 Token 会被脱敏。Agent 本地会话仍可能包含敏感信息，应按开发日志保护。
