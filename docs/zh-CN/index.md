# StateSeal 中文文档

StateSeal 是 Coding Agent 的本地只读交付智能层，只观察 Agent 自有会话、Git
工作区元数据、检查和本地产物，不参与执行。

| 文档 | 用途 |
| --- | --- |
| [快速上手](getting-started.md) | 安装并打开实时全景图 |
| [交付全景图](runs-console.md) | 理解代码状态、检查新鲜度、DAG、诊断和时间线 |
| [产品全景](product-map.md) | 查看架构、模块和路线图 |
| [英文观察模型](../observation-model.md) | 理解数据源、隐私、归因和声明边界 |

当前产品没有受控执行、阻断、审批、Apply 或 Agent 写回能力。
